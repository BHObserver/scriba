## Decisions

- **Welcome uses the red cover.** Opening Scriba is opening a new halkhata. DIRECTION.md now allows the cover on Today, Close and Welcome.
- **Onboarding route `/welcome`**, shown once when there's no `shop_profiles` row. It asks only for language, shop name and morning cash. A new shop is a real shop, so it never shows the sample badge.
- **New-shop Today** shows the cover with the morning cash only, one empty card, and a dashed pointer to the camera button, which pulses. Tiles, the note and the bars appear after the first confirmed page.
- **Error states map to real API outcomes** (table in DESIGN_SPEC):
  - There is no blur detector, so "couldn't read" is shown on `unusable_output`.
  - "Your photo is kept" appears only when the upload actually succeeded.
  - Offline admits there is no queue yet.
  - `previous_uncertain` never re-runs silently.
- **Sideways:** before sending, he checks the orientation and turns the page. Nothing is detected automatically.
- **Learning panel** (P3): it is off by default, and every misread is still checked. It never promises an accuracy figure. His digits stay Bangla in English mode, with the value in brackets, because the confusion is about their shapes.
- **English:** Latin digits with lakh grouping; names and khata text are never translated. A button row stacks when a label needs two lines ("That's what's written", "Take the photo again" at 390 px). Nothing else overflows.
- **Khata page:**
  - Seven fixed columns.
  - Corner markers.
  - Carried-balance and total rows, which feed `cross_record_continuity`.
  - A faint "বা জ" to circle in each row.

## Gotchas

- `money.css` `.chev` has `grid-column: 2`. Don't reuse it in other grids; `Shop Screens.html` overrides it for settings rows.
- Reading prototype files inline costs a lot of context: Bangla is token-heavy and `\u` escapes in writes are worse. Download them with the `render_preview` serve URL into the scratchpad and grep instead. Never write the URL to a file.
- COPY.md is generated by a scratchpad script (`copymd.mjs`: vm-evaluates `data.js`, `shop.js` and `copy.js`, then extracts Bangla literals from the JSX). Regenerate it rather than hand-editing when the prototypes change.
