## How to redeploy

`npx --yes vercel@65.9.0 deploy --prod --yes` from this folder. After an env change, run `bun run vercel:env --yes` and redeploy. The allow-list is set directly on Vercel, not from `.env.local` (empty there): `vercel:env` skips empty values, so it doesn't overwrite it. If `.env.local` ever sets a value, `vercel:env --yes` will overwrite the one on Vercel.
