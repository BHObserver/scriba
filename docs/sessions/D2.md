# D2: prototype 1, the check flow (31 Oct 2026)

**Status:** done. The flow clicks through end to end in the preview, verified by screenshots of every step. No repo code changed.

## What's done (Claude Design project `c10c8807-1a7d-4da4-84c8-c2ed1b2fc687`)

- **`Check Flow.html`**: the interactive prototype: capture (guide frame, page tray, rotate) → reading (three honest steps) → the reveal (boxes draw on the photo, settle green/turmeric) → check deck (problems first, ghost cards, swipe right on plain cards) → fix sheet (Bangla keypad, voice listening → heard → value placed, never auto-saved) → summary (stitched hero, every line with its note) → confirm → the seal. A side panel jumps to any step; `?step=deck` etc. opens a step directly.
- Code, all under 300 lines a file, in `proto/`:
  - `kit.css` holds the tokens and primitives. `flow.css` holds the screens.
  - `kit.jsx` holds the primitives: Phone, TopBar, Chip, Mark, Taka, KhataPage, PageFit, Strip, Seal, Sheet, Keypad, TabBar, Equation.
  - `data.js` holds the page data and a small copy of the checks, so fixes re-run live. It also has `ruleCopy`: one Bangla sentence per real rule id (qty_x_rate, written_total, balance_equation, running_balance, cross_record_continuity, numeral_format, model_uncertainty, classification, unverifiable), which feeds COPY.md in D4.
  - `screens-capture.jsx`, `screens-deck.jsx`, `screens-end.jsx` and `app.jsx` hold the screens and the app.

## Decisions

- **React prototype, not `.dc.html`.** Swipe, the keypad and checks that re-run live are simplest in plain React, and B1–B3 port these components directly. The cost: the editor can't click-edit these files. Comments still work.
- **Demo page = the synthetic S04 example.** Line 1 is read as ৪০০ (written ৮০০), the real 8→4 confusion from HANDOFF. The balance check fails, and a code-computed hint says "হিসাব মিলতে হলে এখানে ৮০০ হওয়া দরকার". Fixing it turns the balance green. The subtotal ৩১০ is wrong in the khata itself; it stays as written.
- **Two accept verbs, matching `approval.ts`.** Plain cards: "ঠিক আছে" (or swipe right). Problem cards don't swipe; they need "খাতায় এটাই লেখা", an explicit acknowledgement, or a fix. Editing a value clears that line's acceptance.
- **Strip crop = the photo positioned by the line's 0–1000 box**, scaled to fit the width (never clipped), with the lines above and below faded to 80%. The app does exactly this with the signed photo.
- **Reveal boxes use `mix-blend-mode: multiply`** so the ink stays dark under turmeric. The "!" badge sits at the box's left edge.
- **Seal** only when every line is accepted and the balance passes. It straddles the page's bottom edge so it never covers a figure. If the balance still fails, the end screen says so, with no seal.
- Reading screen line: "লেখা পড়ে AI, হিসাব মেলায় কোড, শেষ কথা আপনার।" It is the non-negotiable, in plain words. Worth keeping in COPY.md.

## Gotchas for later design sessions

- **The preview wraps every text node in `<span data-om-text>`.** Rules like `.x span {}` hit those wrappers, and text inside grid/flex parents becomes separate items. Wrap mixed text in one span and use `> span` selectors. The seal fix lives in `Check Flow.html`'s inline style. The app doesn't have this problem.
- Glyphs like ↻ fall back to odd fonts in Anek Bangla; draw simple icons in CSS (prototype) or use lucide (app).
- Scratch walk-through script pattern: Playwright (Edge) clicks through the flow and screenshots `.phone` per step. Import `playwright-core` by absolute path from `node_modules` when the script lives in the scratchpad.
