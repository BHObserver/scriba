## Decisions

- **The Ask pill is not shown** until P2 exists. Nothing on screen leads to a feature that isn't built.
- **No "sealed" page state.** `PageInfo` has unread / waiting / checked only, so checked pages get a tick, not the seal. Adding it needs the balance result stored per page.
- **The dues link uses the dues tab's href** (`/records` for now). B5 switches the tab to `/parties`, and the link follows.
- **The camera pulse** on a new shop uses `body:has(.today-new) .cam` in kit.css, so the layout doesn't need to load the shop.
- **Other files touched (one line each):**
  - Track B: `requireUser` now defaults to `next=/`.
  - Track A: `/auth/confirm` now defaults to `/`.
