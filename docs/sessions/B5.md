## What's done

- **`/parties`** (`DuesScreen`): title + badge, পাওনা / দেনা segments, count and total, the waiting-pages panel (all days), risk-ordered rows (top reason in turmeric, else last payment), hint, and an empty state per tab. Centred 640 px column from 768 px.
- **`/parties/[id]`** (`PartyScreen`): top bar (back to the right tab), stitched hero (balance label, reasons, last payment, oldest unpaid), remind (customers with a balance) and merge actions, the "also written as" card with undo, and a timeline newest first: date, page number, strip, verb + reading, ± amount, balance after.
  - The newest 40 lines come with the page; "আরও পুরনো লাইন দেখুন" loads 40 more through `POST /api/lines`.
  - A merged id redirects to its root; an id that isn't his gives 404.
- **Merge sheet:** names with the same first name come first, the search (from 7 names up) goes through `normalizePartyName`, and it says what moves before he confirms. Afterwards it goes to the merged party.
- **Reminder sheet:**
  - The message comes from the template (greeting, Bangla locative of the shop name, last payment, ask, signature) in a textarea he can edit.
  - The picture is the newest ≤ 8 unpaid lines with photos from `/api/crops`, fetched when the sheet opens so `navigator.share` runs inside his tap.
  - Copy uses the clipboard. Send uses Web Share with the file when `canShare` allows; without Web Share it copies the text and says so. A cancelled share changes nothing.
- **`dues-model.ts`** (pure, tested): date and "days ago" labels, quiet reasons, hero label, oldest-unpaid text, Bangla locative and objective, timeline text, balance-after text, reminder lines and photo ids, merge order and search, tab ↔ URL.
- **Shared code:**
  - `readingParts` (from `lineWhat`).
  - `DetailStrip` (from `RecordRow`).
  - The tab bar's dues tab is now `/parties`, so Today's dues link follows. `/records` moved to the আরও tab's match list.
- **i18n:** a "B5" section (`du.*`, `pl.*`, `mg.*`, `rm.*`, bn + en; English written here).

## Decisions

- **The tab bar stays on the ledger** (the prototype dropped it). It's a destination under বাকি, not a flow.
- **The dues total isn't a drill-down button.** The rows are its breakdown, and each opens its lines.
- **Payments and opening balances show only the verb** in the timeline (prototype); the sample repayment's item "জমা" read twice.
- **No reminder for suppliers**, as in the prototype.
- **Only the first name decides "similar" in the merge list.** Endings like উদ্দিন put নাসির উদ্দিন first for রহিম উদ্দিন.
- **The reminder text is editable.** We don't store how he addresses someone (রহিম ভাই), so he can change it.
