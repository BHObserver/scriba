Verified in Edge at 390×844 and 1440×900: sign-in (bn and en), the language switch both ways, the `/kit` board, the sheet with keypad, focus trap and Escape. Check them once `--login` works.

## What's done

- Merged `track-engine` (E1).
- **Tokens:** DIRECTION.md tokens are in `globals.css`. Tailwind names are `paper`, `paper-card`, `ink`, `ink-soft`, `hair`, `khata` (red), `figure` (blue), `ok`, `turmeric`, `gold`, `cream`.
  - The old token names (`accent`, `fail`, `rule`, …) are remapped onto the new palette, so the details pages sit in the shell unchanged. Mismatches are ochre on turmeric-soft (never red). The `danger` button is red.
- **Fonts:** Anek Bangla (with the `wdth` axis) and Noto Serif Bengali, loaded with `next/font`.
- **Kit CSS:** `src/components/kit/kit.css` is loaded into the `components` layer. It uses the prototype class names (`btn`, `card`, `cloth`, `strip`, `eq`, `tabs`…), so porting a screen is mechanical.
- **i18n** (`src/lib/i18n/`):
  - `messages/bn.ts` is the source of keys. `en.ts` must have every key, or the build fails.
  - Part 1 of COPY.md was generated in by script (135 keys); B1 added 29 keys.
  - Use `getI18n()` on the server and `useI18n()` on the client. Both give `t`, `money`, `count`, `digits`, `dayMonth` and `weekday`.
  - `t` fills `{1}`; a number argument is formatted automatically (grouping and the locale's digits).
  - The locale lives in the `scriba_locale` cookie. `useSetLocale()` (server action + refresh) changes it, and `<html lang>` follows.
  - Tests check that bn and en use the same placeholders.
- **Kit** (`src/components/kit/`, barrel `index.ts`):
  - Button / ButtonLink / ButtonRow (with `stack`), Chip, StatusMark, Money, TopBar / BackButton, Cover, SampleBadge, EmptyState, Segmented, Switch.
  - Sheet (`motion`, portal, focus trap, Escape, restores focus), Keypad + `applyKey`, Equation, Seal (land animation, `vibrate(30)`, reduced motion fades).
  - **LineStrip** is a pure-CSS crop. `stripVars()` sets the box fractions and the photo's aspect ratio; container-query units do the rest, with no measuring. It needs `ledger_documents.width/height`.
- **Shell:**
  - The binding band is in the root layout, so it is on every screen. It turns darker on pages with a `.cloth` cover.
  - The `(app)` layout has `RouteTransition` and `TabBar`.
  - Page transitions use React `<ViewTransition>` keyed by pathname: a 220 ms rise, fade only under reduced motion. The band and tab bar have their own transition names and stay still.
- **Sign-in:** restyled as the Welcome cover, with the language choice and the three "how it works" rows (it absorbed the old landing page). Server actions return codes, which the form translates.
- **`/settings`:** language, details links and sign out at the top; the configuration audit is below under "System details". B6 replaces this with the More screen.
- **PWA:** `app/manifest.ts`, `public/icons/`: `icon.svg` (seal with a tick, no text) and PNGs (192, 512, apple 180) from `scripts/icons.ts`. Next's default `favicon.ico` is removed.
- **`/kit`:** every primitive on one screen inside the shell, in the current language. It is development only (`notFound()` in production) and open without signing in (the proxy allows it outside production).

## Decisions

- **Interim tab targets** (`src/components/shell/tabs.ts`), so no tab leads to a 404:
  - Today → `/`, which redirects to `/documents` until B4.
  - Khata → `/documents`; Dues → `/records`; camera → `/documents#upload`.
  - B2, B4, B5 and B6 each change one line there.
- **English for COPY.md part 2 (D2/D3) is left to the session that ports each screen** (B2 capture/reveal, B3 deck/rules, B4 Today/close, B5 dues, P2 ask). Keys only make sense once a component uses them, and each of those sessions reads its section anyway. Use part 1's plain register; the parity tests catch gaps. This reverses D4's suggestion, deliberately.
- **Page transitions use ViewTransition, not `motion`.** `motion` is used for the sheet and seal, and later for the swipe.
- **The seal in English** reads "It all adds up". The serif font has Latin glyphs.
- **Theme colour:** paper by default. Cover screens export `viewport.themeColor = "#972622"`, as login does.
